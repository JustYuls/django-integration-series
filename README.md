# Integrative Programming with Django: From Scripts to a Secure App

A 12-part video series and code, from simple scripts to a complete, secure Django application.
Built for the course CSIPT101 Integrative Programming Technologies 1, and open for anyone learning.

Each part has a folder with code and tests. Parts 1 to 3 are standalone scripts. Parts 4 to 12 grow one Django project, the **Campus Booking Hub**.

## Course outcomes covered

| Course outcome | Parts |
|---|---|
| CO1: Scripting and client-server architecture, with Generative AI | 1 to 3 |
| CO2: Set up and configure a Django project, with Generative AI | 4 to 6 |
| CO3: Data-driven Django apps and API consumption, with Generative AI | 7 to 9 |
| CO4: Design, secure, optimize and present a complete application | 10 to 12 |

## What you need

- Python 3.12 or newer
- Node.js 18 or newer (Part 1 only, for the JavaScript example)
- From Part 4: a virtual environment and `pip install -r requirements.txt` (Django 6.1.3), see the README of that part

The narration in the videos is a synthetic (text-to-speech) voice and the presenter is an animated cartoon.
